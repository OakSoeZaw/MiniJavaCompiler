# miniJava Semantic Rules

## 1. Error reporting
- Errors go to stderr as `Semantic error at line N: <message>`.
- Semantic checking runs only after a parse with no syntax errors.
- One mistake gives one message. A bad expression gets the type `<error>`,
  which is compatible with every type, so it causes no follow-up errors.
- Final status: `Semantic check completed with N errors`, or
  `Parse successful` if there are none.

## 2. Passes
1. Class table: register the main class and all classes; report duplicates.
2. Inheritance: undefined parent, extends itself, extends main, cycles.
3. Members: duplicate fields/methods/parameters/locals, unknown class types,
   override signature check.
4. Bodies: type-check all statements and expressions.

## 3. Decisions
- **No overloading.** Two methods with the same name in one class are a
  duplicate. A method with the same name as an ancestor's method must have the
  identical return type and parameter types.
- **Names.** Lookup order: locals, parameters, fields of the class, fields of
  its ancestors. A local may shadow a field but may not reuse a parameter name.
- **Subtyping.** int, boolean and int[] are subtypes only of themselves. A
  class B is a subtype of A if B is A or inherits from A.
- **Assignment, arguments, return.** The expression type must be a subtype of
  the target type.
- **null.** Assignable to any class type and to int[]; not to int or boolean.
- **== and !=.** Allowed when one operand type is a subtype of the other
  (int/int, boolean/boolean, related references, reference/null). Result is
  boolean. Mixed primitive/reference or int/boolean is an error.
- **Operators.** `+ - * / %` int,int -> int. `< <= > >=` int,int -> boolean.
  `&& ||` boolean,boolean -> boolean. `!` boolean -> boolean.
- **Arrays.** `a[i]` needs int[] and int; `a.length` needs int[];
  `new int[e]` needs int e; `a[i] = e` needs int[], int, int.
- **Conditions.** `if` and `while` conditions must be boolean.
- **println.** Accepts int or boolean. Rejects int[], class types and null.
  (Required by the extension samples null_refs and ops_relational, which
  print boolean values.)
- **Calls.** Receiver must be a class type; the method is searched in that
  class and its ancestors; argument count must match; each argument must be
  a subtype of its parameter; result is the declared return type.
- **Main class.** `extends Main`, `new Main()` and using Main as a type are
  errors. `this` inside main is an error.
